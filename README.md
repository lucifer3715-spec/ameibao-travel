# 🦭 阿咩豹的旅行手账 (`ameibao-travel`)

长着**圆鼓鼓豆豆眉**和**立体花生嘴筒子**的斑海豹幼崽 **阿咩豹**，帮你们两个人收好旅途中的每一顿好吃的、每一处好看的风景、路上的悄悄话与下一站旅行心愿。

## ✨ 功能亮点

- **🍜 美食图鉴 & 🏞️ 景点足迹双核心模块**：支持按城市地点一键筛选、按城市折叠分组、标签与关键词检索、星级打分与「阿咩豹推荐红章」。
- **📸 多图相册与自动瘦身上传**：每篇游记最多上传 9 张照片，支持自定义图注、一键切换封面、全屏高清灯箱左右翻看；手机原图在浏览器端自动高清压缩，自有服务器秒传不占空间。
- **💬 双人专属评语贴纸**：除了游记正文外，还可以分别写下「我的嘴替评语」与「女朋友的嘴替评语」，在卡片上像手账对话气泡一样展示。
- **🧭 城市足迹册**：去过的每一座城市自动汇成一张邮戳明信片，点开即可一页重温当地吃过的全部美食与逛过的全部景点。
- **🫧 碎碎念漂流瓶**：随时丢一张带心情小表情、定位或配图的便签，支持点小心心连击、置顶，以及在对方纸条下直接接话盖楼。
- **🎒 下一站旅行计划簿**：支持出发倒计时、预算与路线备忘，分设「想吃美食 / 想去景点 / 行前准备」三栏清单；打卡后点 **「✨ 写游记」** 即可一键转成正式游记并自动关联！
- **🔒 私密暗号保护 & 一键完整备份**：零第三方依赖，仅需 `Node.js 18+` 即可在自有服务器运行，支持一键下载/恢复包含全部照片的 `.json` 备份文件，也支持添加到手机主屏幕全屏使用。

## 🚀 本地立刻预览

```bash
cd ameibao-travel
node server.mjs
```

浏览器打开 `http://127.0.0.1:8799`（未配置 `.env` 时默认演示暗号为 `ameibao`）。

上线到你自己的服务器请查看 **[SERVER_DEPLOY.md](./SERVER_DEPLOY.md)**。
